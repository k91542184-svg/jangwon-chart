보조지표
종목

      화면 왼쪽 첫 봉을 기준으로 같은 출발점에서 수익률을 비교합니다. 최대 3개.

      종목 찾기

        장 마감 스캐너

        폴더 안 종목의 일봉을 검사합니다. 고른 조건을 모두 만족하는 종목이 위에 옵니다.

        검사할 폴더

        장 마감 데이터 자동 받기

        Twelve Data 무료 API로 관심 폴더 종목의 일봉과 30분봉을 한 번에 받습니다. 이미 받은 종목은 빠진 날짜만 이어 받습니다.

        Claude 링크에서는 외부 데이터 연결이 막혀 있습니다. PC에 저장한 장원차트.html 파일을 브라우저로 열어서 이 기능을 쓰세요. 이 화면에서는 CSV 불러오기를 쓸 수 있습니다.
        서버에 아직 없는 종목

        종목을 더하거나 빼려면 GitHub 저장소의 config.json을 고쳐 저장하세요. 몇 분 뒤 자동으로 받아지고, 이 화면에 바로 반영됩니다. 아래 버튼을 누르면 지금 프로그램의 관심 폴더 구성이 config.json 형식으로 복사됩니다.
        받을 종목
        무료 요금제는 1분에 8번까지 요청할 수 있어서, 종목 하나에 약 8초씩 걸립니다. 21종목 일봉이면 3분 정도입니다. 키는 이 브라우저에만 저장됩니다.

        알림선 확인

        알림을 켠 수평선·추세선을 마지막 봉이 건드렸는지 데이터를 받을 때마다 검사합니다.

          CSV 불러오기

          종목별 CSV 여러 개를 한 번에 넣을 수 있습니다. 파일 이름에서 종목 코드를 읽고, 일봉인지 분봉인지는 자동으로 구분합니다.

          CSV 파일들을 여기에 끌어다 놓거나
          표를 직접 붙여넣기
          • 일봉: Yahoo Finance 종목 페이지 → Historical Data → Download, 또는 Stooq CSV
          • 30분·1시간봉: 30분 이하 간격의 분봉 CSV가 필요합니다 (TradingView 차트 데이터 내보내기, 증권사 HTS 저장 파일 등)
          • 같은 종목을 다시 불러오면 기존 데이터에 이어 붙입니다. 매일 최근 며칠치만 넣어도 됩니다.

          지표 설정

          바꾸는 즉시 차트에 반영됩니다.

          사용법

          • 매일 쓰는 순서장 마감 후 ‘데이터 받기’ → 관심 폴더 전체 자동 갱신 → ‘알림’ 확인 → ‘스캐너’로 후보 고르기 → ↑ ↓로 종목을 넘기며 차트 확인
          • 데이터 받기Twelve Data 무료 API 키를 한 번 넣으면 폴더 단위로 일봉·30분봉을 받습니다. 이미 받은 종목은 빠진 날만 이어 받습니다. PC에 저장한 HTML 파일에서 작동하고, Claude 링크에서는 CSV를 쓰세요
          • 종목 넘기기차트를 보다가 ↑ ↓로 관심목록의 이전·다음 종목. 영문 글자를 치면 검색창. 확대 상태는 종목을 바꿔도 그대로 유지됩니다
          • 관심 폴더⋯ 버튼으로 만들기·이름 바꾸기·삭제. ‘직접 순서’일 때 종목을 끌어서 순서 바꾸기. 작은 선 그래프는 최근 40일 흐름, 주황색 날짜는 다른 종목보다 오래된 데이터
          • 차트 이동·확대끌기, 마우스 휠, 두 손가락, 날짜 축 끌기, ← → + −, 위쪽 기간 버튼. 두 번 클릭하면 보기 초기화
          • 가격 축가격 축을 위아래로 끌면 수동 모드가 되어 차트를 위아래로도 옮길 수 있습니다. 오른쪽 아래 ‘자동’이나 가격 축 두 번 클릭으로 자동 맞춤. ‘로그’, ‘%’ 눈금도 여기서
          • 오른쪽 클릭그 가격에 수평선·알림선 긋기, 그림 복제·잠금·삭제, 이미지 저장
          • 그리기도구를 고른 뒤 두 점을 끌거나 한 번씩 클릭. 그림을 누르면 위쪽에 색상·굵기·점선·알림·복제·잠금·삭제 막대가 나옵니다. Ctrl+Z 되돌리기
          • 포지션진입 가격에서 목표가까지 끌면 손절선(기본은 목표의 절반 거리)과 손익비가 표시됩니다. 손절선은 아래쪽 점을 끌어 조정. 이후 봉이 목표나 손절에 먼저 닿았는지도 보여 줍니다
          • 알림선수평선·추세선·연장선에 알림을 켜 두면, 데이터를 받을 때 마지막 봉이 선을 돌파하거나 이탈했는지 검사해 ‘알림’에 쌓고 관심목록에 빨간 점을 찍습니다
          • 보조지표 창창 오른쪽 위 ▲▼로 순서, ⚙ 설정, ✕ 닫기. 경계선을 끌어 높이 조절
          • 리플레이시작할 봉을 클릭하면 그 뒤가 가려집니다. ← → 또는 재생 버튼으로 한 봉씩
          • 단축키Alt+T 추세선 R 연장선 H 수평선 L 수직선 C 채널 F 피보나치 B 사각형 N 메모 A 매수매도 P 포지션 M 측정 V 이동
          • 지표 해석심리도 75% 과열·25% 침체, 스토캐스틱 80·20, ADX 25 이상이면 추세가 강함. 일목균형표 구름은 26봉 앞으로 그려집니다. VWAP은 분봉 전용

          데이터와 그린 선, 폴더는 이 브라우저에 저장됩니다. ‘연습용’ 폴더의 데모 종목은 가상 가격입니다.
